Provisioning (manual)

serviceUser.enabled is false, so the chart did NOT create the service identity
or catalog entry. Run these one-time steps as an operator with an admin token:

1. Verify the deployment:

     kubectl -n {{ include "substation-mcp.namespace" . }} get deploy substation-mcp

2. Run register-catalog (one-time, as an operator with an admin token):

     OS_CLOUD={{ $cloud }} REGION={{ $region }} \
     PUBLIC_URL={{ $publicURL }} \
     ./deploy/register-catalog.sh

3. Connect an MCP client:

     claude mcp add --transport http openstack \
       {{ $publicURL }} \
       --header "Authorization: Bearer <keystone-token>"
